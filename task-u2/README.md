# Entrega — Projeto da II Unidade

O pacote reúne os artefatos solicitados, exceto o painel MVP, que foi deixado de fora conforme orientação:

- [Documento de Requisitos](./documento-de-requisitos.md): capa editável, introdução, tecnologias, estórias de usuário com critérios de aceitação, especificações de casos de uso e análise de riscos.
- [Protótipos de baixa resolução](./prototipos-baixa-resolucao.md): wireframes conceituais das telas principais.
- [Diagrama de casos de uso](./diagrama-casos-de-uso.puml): fonte UML em PlantUML.

Antes da entrega, preencher os campos da capa e revisar os itens de validação descritos ao final do documento de requisitos.
